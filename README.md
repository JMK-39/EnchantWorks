# Enchant Works

> V1.0

## 简体中文

扩展铁砧、附魔规则和装备附魔玩法。

### 核心功能

- 调整铁砧费用、维修惩罚、经验消耗及重命名成本。
- 按物品与附魔组合设置允许列表、禁止列表和全局禁用规则。
- 扩展部分原版附魔，并提供熔炼、汲取、第六感、启蒙、万能工具五种附魔。

### 使用

按 **F6** 进入 Enchant Works 配置页。服务端负责执行附魔规则；自定义附魔注册禁用项须在启动时确定。

### 前置依赖

必需：Forge 47.4.2+、KineticCore 26.9.20+。

## English

Extends anvils, enchantment rules, and equipment enchantment gameplay.

### Features

- Adjust anvil costs, repair penalties, XP consumption, and renaming costs.
- Configure item/enchantment allowlists, denylists, and global disable rules.
- Extend selected vanilla enchantments and add Smelter, Leech, Sixth Sense, Enlightenment, and Omni Tool.

### Usage

Press **F6** to open Enchant Works settings. Enchantment rules are enforced by the server; custom-enchantment registration exclusions are determined at startup.

### Requirements

Required: Forge 47.4.2+, KineticCore 26.9.20+.
